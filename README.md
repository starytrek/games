# Starytrek · Nauka

Portal z testami interaktywnymi i grą geograficzną. Zwykłe HTML, bez instalacji i kompilowania.

## Publikacja pod głównym adresem

1. Utwórz publiczne repozytorium `starytrek/starytrek.github.io` z plikiem README.
2. Skopiuj `index.html` i katalog `testy` do tego repozytorium.
3. W Settings → Pages wybierz Deploy from a branch → main → / (root) → Save.
4. Portal będzie dostępny pod `https://starytrek.github.io/`. Gra pozostaje pod dotychczasowym adresem.

## Dodawanie materiałów

Dodaj plik HTML lub PDF do `testy/<przedmiot>/`, a następnie dodaj kartę w `index.html`: tytuł, opis, przedmiot w `data-subject` i względny adres pliku. Filtry i wyszukiwarka obejmują nowe karty automatycznie. Sama lista kart jest obecnie uzupełniana ręcznie; można zlecić to asystentowi.

Obecne testy są kopiami wcześniejszych autorskich materiałów. Do każdej kopii dodano powrót do katalogu. Brak kont i zbierania wyników przez portal.
